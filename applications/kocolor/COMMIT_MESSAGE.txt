Fix Settings Navigation Backstack Clearing Bug

This commit resolves an issue where navigating to the Settings screen from deep within the application (e.g., via the AI Status pill on the Style Simulator) would clear the navigation backstack, rendering the top back arrow non-functional.

Summary of Changes:
1. **Intelligent Stack Pushing**: Updated `MainViewModel.kt`'s `navigateTo()` function. If the user navigates to a top-level route (like Settings) while a deep backstack already exists (`size > 1`), the route is pushed onto the stack rather than resetting it.
2. **Top-Level Route Matching**: Refactored the `topLevelRoutes` check to evaluate `it::class == route::class` instead of an exact object match, ensuring routes with nullable payload arguments (like `KoColorRoute.Settings(null)`) are correctly identified.

Status: Build successful.
