Wire Local AI NPU Hardware Check to UI Badge

This commit fixes the hardcoded Local AI availability state in the Settings menu so that it accurately reflects the physical hardware capabilities of the user's device (e.g. Pixel 9a without a working NPU vs Pixel 9 Pro).

Summary of Changes:
1. **Module Dependencies**: Added `:features:ai:local` as an explicit dependency for `:features:ai:configuration` in `build.gradle.kts` to expose the local engine.
2. **Dynamic Hardware Validation**: Injected `LocalAiEngine` into `AiConfigurationViewModel.kt` and updated `checkLocalAiAvailability()` to evaluate `localAiEngine.checkCapability()` asynchronously on init.
3. **UI Badge Reflection**: The `NPU Active` / `Unsupported` badge in the UI will now accurately display a red circle and state "Unsupported" if the device lacks Gemini Nano compatibility.

Status: Verified and build successful.
