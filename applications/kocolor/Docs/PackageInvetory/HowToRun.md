### How to Run the Payload Generator

**Step 0: Set Security Keys**
Before running the generator, you must set your private signing key as an environment variable. Create a `.env` file in `server/kocolor/` or export it in your shell:
```bash
export CDN_PRIVATE_KEY_HEX="your_private_key_hex"
```
You can use the provided `.env.example` as a template.

**Step 1: Navigate to the specific crate directory**
```bash
cd server/kocolor
```

**Step 2: Run the binary that compiles the definitions into JSON**
```bash
cargo run --bin generate_payload
```

### What This Command Does

When you run this command, the Rust compiler validates all item definitions (like `lips.rs` or `complexion.rs`) for strict type safety. If the build succeeds, the binary will generate or update the following files:

1. **`starter-pack.json`**: The complete high-fidelity master library.
2. **Seasonal Packs**: Specific sub-collections (e.g., `winter-essentials.json`).
3. **`manifest.json`**: The dynamic master manifest that lists all available packs, their versions, and item counts.

Once generated, you upload these JSON files (along with the `.webp` images generated by your optimization script) to your GitHub Pages repository.
