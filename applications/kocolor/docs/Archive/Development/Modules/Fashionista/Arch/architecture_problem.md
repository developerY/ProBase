# One thing I would change in your latest FASHIONISTA plan

Your latest plan is very close, but I would make one conceptual correction.

You currently call the output:

> **"reference-calibrated computational fashion-aesthetic score"**

That's good.

But the phrase:

> "derived offline from expert-rated reference ensembles"

means FASHIONISTA's **implementation remains deterministic**, but its calibration parameters are learned/fit offline.

That is perfectly reasonable.

The distinction should be explicit:

```text
OFFLINE:
Expert-rated ensembles
        ↓
Parameter fitting/calibration
        ↓
Frozen FashionistaCalibration
        ↓
shipped with KoColor

RUNTIME:
Observed outfit
        ↓
Deterministic mathematics
        ↓
Frozen parameters
        ↓
Score 0–100
```

So there is **no ML/LLM inference at runtime**.

# One more important issue

I would **not make the score depend on whether a face is present**.

Your `coverage` concept is good, but the semantics should be:

```text
Score = what the observable outfit itself scores

Coverage = how much of FASHIONISTA's measurement system
           was actually observable
```

For example:

### Flat-lay

```text
Score:     86.4
Coverage:  0.82
```

### Full-body photograph

```text
Score:     88.1
Coverage:  0.97
```

The missing face doesn't mean:

```text
"the outfit is worse"
```

It means:

```text
"we measured fewer dimensions of the complete visual system."
```

That distinction is **very important**.
