# Seaweed Mobile 📱

The primary financial hub for the Seaweed ecosystem, built with the "Gold Standard" of Modern Android Development.

## Architectural Excellence

*   **Reactive State**: Derives complex financial calculations (Amortization, Income Deductions) reactively from multiple data streams.
*   **Adaptive Layouts**: Full support for large screens and foldables using `ListDetailPaneScaffold`.
*   **Modular Features**: Strictly separated feature modules for maintainability and build speed.

## Feature Modules

*   `:features:home`: The "Real Money" dashboard.
*   `:features:bills`: Cyclic bill management and amortization logic.
*   `:features:transaction`: Daily spending tracking.
*   `:features:settings`: Reactive configuration and theme switching.
