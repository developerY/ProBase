# Seaweed Wear OS App

This is the Wear OS version of the Seaweed budgeting application. It provides quick access to your financial summary and recent transactions directly from your wrist.

## Features

- **Total Balance**: View your current total balance at a glance.
- **Recent Transactions**: Scroll through your latest spending.
- **Quick Add**: Easily add random transactions for testing or quick data entry.

## Architecture

Built using modern Android development practices:
- **Jetpack Compose**: For the entire UI.
- **Wear Compose Material3**: Following the latest design guidelines for Wear OS.
- **Navigation 3**: For state-based navigation with native swipe-to-dismiss support.
- **Shared Data Layer**: Reuses the same database and repositories as the mobile app.
