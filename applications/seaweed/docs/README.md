# Seaweed Documentation

Welcome to the Seaweed application documentation. This directory is organized into logical domains to help developers, designers, and maintainers find information quickly.

## Directory Structure

*   **`architecture/`**: High-level system architecture, engine implementations, core concepts, security, safety, and privacy infrastructure (e.g., `financial_document_engine_implementation.md`, `seaweed_security_privacy_architecture.md`).
*   **`legal/`**: Compliance documents including the Privacy Policy and Data Deletion instructions.
*   **`publishing/`**: Google Play Store assets, app store descriptions, and release metadata.
*   **`user_guides/`**: Manuals and end-user documentation illustrating the app's features and workflows.
*   **`archive/`**: Historical documents, technical build specifications, AI planning (GenAI), and out-of-date features (BlockChain).
