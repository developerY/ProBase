# XR Glasses Module

This module contains samples for the **Full XR Glasses** experience.

## Overview

The samples are categorized into three tracks:

### 1. Spatial UI (Compose XR)
Showcases how to build 3D user interfaces.
- **Spatial Panels:** Move 2D UI into 3D.
- **Orbiters:** Auxiliary UI that follows a main panel.
- **Subspaces:** Dedicated 3D regions.

### 2. 3D Graphics (SceneCore)
Lower-level manipulation of the 3D world.
- **GLTF Support:** Loading industry-standard 3D models.
- **Anchoring:** Persisting virtual objects on physical surfaces.
- **Entities:** Direct manipulation of the scene graph.

### 3. Perception (ARCore)
Understanding the physical world.
- **Planes:** Detecting floors and walls.
- **Tracking:** 6DoF user positioning.
- **User Sensors:** Face, eye, and hand tracking capabilities.

## Execution
Use the **XR Glasses Emulator** from the Android Studio Device Manager to run this module.
Navigate to the **Full XR Showcase** from the app's feature list.
