# The Temperature Facet

One of the five Professional Facets is **Temperature**.

This attribute describes the underlying chromatic bias of a cosmetic product.

The Glow Archive defines four primary temperature classifications.

| Temperature | Description |
|-------------|-------------|
| **Warm** | Golden, peach, and yellow-biased tones |
| **Cool** | Blue, pink, and rosy-biased tones |
| **Neutral** | Balanced between warm and cool |
| **Olive** | Muted green-influenced undertones |

These classifications provide the foundation for intelligent shade recommendations and undertone matching. :contentReference[oaicite:1]{index=1}

# CIELAB Color Space

The Glow Archive bases temperature analysis on the **CIELAB (`L*a*b*`)** color model.

This standardized color space separates brightness from chromatic information.

| Axis | Meaning |
|------|---------|
| **L\*** | Lightness (0 = Black, 100 = White) |
| **a\*** | Red ↔ Green axis |
| **b\*** | Yellow ↔ Blue axis |

Using CIELAB allows KoColor to compare colors numerically rather than relying on subjective visual descriptions. :contentReference[oaicite:2]{index=2}

# Temperature Classification

The Temperature Facet is derived from the relationship between the chromatic coordinates.

| Temperature | Color Characteristics | Typical Undertones |
|-------------|----------------------|--------------------|
| Warm | Higher yellow contribution | Golden, Peach |
| Cool | Greater blue influence | Pink, Rosy |
| Neutral | Balanced chromaticity | Universal |
| Olive | Muted green influence | Olive, Neutral-Green |

These categories allow recommendation engines to match products with compatible skin undertones while maintaining visual harmony. :contentReference[oaicite:3]{index=3}
