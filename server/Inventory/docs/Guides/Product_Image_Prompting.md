### Tips for Best Results

* **Keep Descriptions Visual:** When filling out the product descriptions, focus entirely on visual traits (material, texture, color, shape) rather than abstract concepts (e.g., instead of "hydrating formula," use "glossy liquid texture").
* **Consistency:** If you are generating a set of identical containers (like mascara tubes or lipstick bullets) with different colors, explicitly state the container shape in every single bullet point so the AI maintains a uniform product line.
* **Text Accuracy:** AI image generators occasionally struggle with perfect text spelling. Keeping the IDs and Names short will yield the cleanest results for your placeholder text.
