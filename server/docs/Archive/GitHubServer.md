# 🌐 KoColor Static Backend & CDN Architecture Setup

This document serves as the master reference for the KoColor backend. We utilize a 100% free, zero-maintenance, offline-first architecture. 

Instead of running an active cloud server, we generate a static JSON payload via a local Rust script and host it alongside our optimized WebP image assets on GitHub Pages. This infrastructure is routed through a secure, custom subdomain to permanently protect the Android API contract.

---

## 1. Domain & DNS Configuration

To prevent clashes with the main marketing website (hosted on Google), the backend operates on an isolated custom subdomain (`cdn.kocolor.com`). The CNAME record must point to your default GitHub Pages domain.

**In your Namecheap DNS Manager:**
*   Leave the existing `www` and `@` records untouched to protect the main website.
*   Create a new **CNAME Record**:
    *   **Host:** `cdn`
    *   **Value:** `developerY.github.io.` *(Note the required trailing period)*

**In your GitHub `kc-cdn` Repository:**
1.  Navigate to **Settings** > **Pages**.
2.  Under **Custom domain**, enter `cdn.kocolor.com` and click **Save**.
3.  Once the DNS check passes, check the box to **Enforce HTTPS**. This provisions a free SSL certificate, which is strictly required to pass Android's network security policies.

---

## 2. Repository Structure

The `kc-cdn` repository is configured to act as our CDN. The Android API payload and assets are neatly contained within an `inventory` subdirectory.

Your repository tree must match this structure before pushing to the `main` branch:

```text
/ (Root of your GitHub repository)
├── README.md                <-- Default landing page shown in browsers
└── inventory/               <-- API Root Path
    ├── starter-pack.json    <-- The compiled payload generated by Rust
    └── assets/                  
        ├── image_07157d.webp    <-- Optimized image assets (30KB-50KB)
        └── image_45f6fe.webp

```

## 3. Payload Generation (Rust)

Because we rely on static hosting, the backend logic executes locally on your machine *before* deployment. The domain models are compiled into a static `starter-pack.json` file inside the `ProBase` monorepo.

**File:** `ProBase/server/kocolor/src/bin/generate_payload.rs`

```rust
use serde::Serialize;
use std::fs::File;
use std::io::Write;

#[derive(Serialize)]
struct CosmeticItem {
    id: String,
    name: String,
    category: String,
    image_url: String, 
}

fn main() {
    let items = vec![
        CosmeticItem {
            id: "lip_001".to_string(),
            name: "Crimson Matte".to_string(),
            category: "Lipstick".to_string(),
            // Ensure URLs point directly to the new custom domain and /inventory path
            image_url: "[https://cdn.kocolor.com/inventory/assets/image_07157d.webp](https://cdn.kocolor.com/inventory/assets/image_07157d.webp)".to_string(),
        },
        // Add additional starter inventory items here...
    ];

    let json_payload = serde_json::to_string_pretty(&items).expect("Failed to serialize");
    
    let mut file = File::create("starter-pack.json").expect("Failed to create file");
    file.write_all(json_payload.as_bytes()).expect("Failed to write JSON");

    println!("✅ Successfully generated starter-pack.json!");
}

```

**Deployment Workflow:**

1. Run `cargo run --bin generate_payload` locally.
2. Move the generated `starter-pack.json` into the `kc-cdn/inventory/` directory.
3. Commit and push to GitHub.

## 4. Android Client Configuration

The Jetpack Compose application interacts with the static CDN exactly as it would a dynamic server, benefiting from instant download speeds and zero cold-start delays.

**Retrofit Network Client:**
Set your base URL to the custom subdomain and inventory path. Ensure the URL ends with a trailing slash.

```kotlin
val retrofit = Retrofit.Builder()
    .baseUrl("[https://cdn.kocolor.com/inventory/](https://cdn.kocolor.com/inventory/)") 
    .addConverterFactory(GsonConverterFactory.create())
    .build()

```

**Retrofit Interface:**

```kotlin
interface KoColorApi {
    @GET("starter-pack.json")
    suspend fun getStarterPack(): Response<List<CosmeticItem>>
}

```

**Asset Loading (Coil):**
The parsed `CosmeticItem` objects will contain absolute URLs (e.g., `https://cdn.kocolor.com/inventory/assets/...`). When passed to Coil's `AsyncImage` composables, Coil will automatically fetch, cache, and render the WebP files locally on the device.
