# Classic Product Specifications

## Reference Products for the Glow Archive Taxonomy

To establish a consistent foundation for the KoColor catalog, the Glow Archive defines a set of canonical cosmetic products.

These products serve as architectural reference implementations for:

- Taxonomy validation
- Recommendation engine testing
- Compatibility analysis
- Color science benchmarking
- UI demonstrations

Each product represents a distinct combination of:

- Anatomical application zone
- Physical formulation
- Base chemistry
- Visual finish
- Coverage profile
- Temperature classification

Together, they provide baseline standards for the entire cosmetic ecosystem. :contentReference[oaicite:0]{index=0}

# KoColor Signature Crimson Lip Color

## The Classic Neutral Red

The Signature Crimson Lip Color serves as the canonical example of a classic neutral red lipstick.

Its balanced pigment composition establishes a benchmark for:

- Lip color rendering

# KoColor Velvet Canvas Primer

## The Foundational Base Layer

The Velvet Canvas Primer represents the first stage of the cosmetic application pipeline.

Its purpose is to create a uniform surface before complexion products are applied.

---

### Taxonomy Mapping

| Attribute | Value |
|-----------|-------|
| **Macro Category** | Skincare & Prep |
| **Micro Category** | Primer |
| **Formulation** | Gel |
| **Chemistry** | Silicone |
| **Finish** | Matte |
| **Coverage** | Sheer |
| **Temperature** | Neutral |

---

### Architectural Role

The silicone gel formulation establishes a stable base layer that subsequent complexion products can build upon.

Within the compatibility engine, this product acts as an anchor point for evaluating chemical interactions between primer and foundation layers. :contentReference[oaicite:3]{index=3}

# KoColor Sculpt & Define Contour Powder

## Creating Natural Facial Structure

The Sculpt & Define Contour Powder represents the canonical contour product within the Glow Archive.

Its purpose is to simulate natural facial shadow rather than warmth.

---

### Taxonomy Mapping

| Attribute | Value |
|-----------|-------|
| **Macro Category** | Color & Dimension |
| **Micro Category** | Contour |
| **Formulation** | Powder |
| **Chemistry** | Silicone |
| **Finish** | Matte |
| **Coverage** | Buildable |
| **Temperature** | Cool |

---

### Architectural Role

The cool temperature classification distinguishes contour products from bronzers.

Recommendation algorithms use this distinction to ensure structural shadow is created without introducing unintended warmth into the user's complexion. :contentReference[oaicite:4]{index=4}

# Why Reference Products Matter

Reference products provide a stable foundation for the Glow Archive ecosystem.

They enable:

- Validation of taxonomy mappings.
- Consistent recommendation benchmarks.
- Reliable compatibility testing.
- Standardized UI demonstrations.
- Repeatable AI evaluation.

Rather than acting as ordinary catalog entries, these products define the expected behavior of their respective cosmetic categories.
