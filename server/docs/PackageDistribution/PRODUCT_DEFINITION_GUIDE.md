# KoColor Product Definition Guide (JSON)

This guide explains how to define products in the JSON format used by the KoColor Normalization Compiler to generate `.kpkg` distribution artifacts.

## The Product Envelope

Every package consists of a root `StarterPackResponse` object containing two arrays: `cosmetics` and `clothing`.

```json
{
  "version": 1,
  "cosmetics": [ ... ],
  "clothing": [ ... ]
}
```

---

## 1. Defining a Cosmetic Item

Cosmetic items power the AI styling routines and skin-compatibility engines.

### Minimal Example (Required Fields Only)
```json
{
  "id": "kc-mac-ruby-woo",
  "name": "Ruby Woo Lipstick",
  "brand": "MAC",
  "macro_category": "LIPS",
  "micro_category": "LIPSTICK",
```

## 🔍 Validation Checklist (The "AI-Safe" Rule)

To ensure the Android app and its AI features function correctly, follow these rules:

1.  **Categories**: MUST be strictly uppercase (e.g., `PREP`, `LIPS`, `TOPS`). See `CANONICAL_SCHEMA.md` for the full list.
2.  **Enums**: Values like `formulation`, `finish`, and `temperature` MUST match the schema exactly.
3.  **Hashed Filenames**: When deploying, always use the content-addressed name generated by the compiler (`<id>-<hash>.kpkg`).
4.  **Minification**: JSON in the final `.kpkg` should be minified for speed, but you can write your source definitions with whitespace.

## 🚀 Appendix: Valid Enum Reference

### Macro Categories
- **Cosmetic**: `PREP`, `COMPLEXION`, `DIMENSION`, `EYES`, `LIPS`, `NAILS`, `HAIR`, `HYGIENE`, `ORAL`, `FRAGRANCE`, `GROOMING`, `TOOLS`
- **Clothing**: `TOPS`, `BOTTOMS`, `OUTERWEAR`, `DRESSES`, `ACCESSORIES`

### Professional Facets
- **Formulation**: `LIQUID`, `CREAM`, `POWDER`, `GEL`, `BALM`, `PENCIL`, `SPRAY`, `STICK`
- **Finish**: `MATTE`, `SATIN`, `NATURAL`, `DEWY`, `RADIANT`, `GLOSSY`
- **Chemistry Base**: `WATER`, `SILICONE`, `OIL`, `WAX`, `ALCOHOL`
- **Coverage**: `SHEER`, `LIGHT`, `MEDIUM`, `FULL`, `BUILDABLE`
- **Temperature**: `WARM`, `COOL`, `NEUTRAL`, `OLIVE`
